---
title: "快速验证"
description: "先确认 Key 的模型列表，再运行对应能力的实测示例。"
---

1. 在运行环境中设置 `HEIHUZI_API_KEY` 为自己的 API Key。
2. 运行下面的查询，检查 `models.json` 的 `data[].id`。
3. 按查询结果选择对应接口示例。

```bash
curl --fail-with-body --silent --show-error --max-time 600 \
  --request GET \
  --url https://code.heihuzi.ai/v1/models \
  --header "Authorization: Bearer $HEIHUZI_API_KEY" \
  --output models.json
```

| 想完成的操作 | 使用入口 |
| --- | --- |
| GPT 文本 | [Responses](/cn/api-reference/responses) |
| Messages 文本 | [Claude Code Messages](/cn/api-reference/messages) |
| 生成图片 | [GPT Image 2.5 图像生成](/cn/api-reference/images/gpt-image-2/generation) |
| 修改参考图 | [GPT Image 2.5 图像编辑](/cn/api-reference/images/gpt-image-2/edits) |

图片返回的是 base64 数据，使用 [SDK 示例](/cn/integrations/openai-sdk)保存为 PNG 文件；流式示例会保存预览和最终图片。
