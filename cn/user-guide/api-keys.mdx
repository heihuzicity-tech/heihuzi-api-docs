---
title: "API Key 使用"
description: "用对应能力的 Key 查询模型并运行示例。"
---

在运行环境中设置文档示例使用的 `HEIHUZI_API_KEY`。真实 Key 应保存在服务端环境变量或密钥管理服务中，避免写入公开代码或分享截图。

先请求 [Models](/cn/models)。本次文本、Messages、图片 Key 的模型列表不同，图片权限不足的 Key 调用 Images 返回 403；认证成功后还需要使用正确的能力和模型。

Codex CLI 的实测命令使用 `HEIHUZI_ACCEPTANCE_API_KEY`；Claude Code 使用 `ANTHROPIC_AUTH_TOKEN`。变量名和 Base URL 按[对应客户端页面](/cn/integrations/index)填写。

错误排查见[认证与权限](/cn/faqs/auth-and-permissions)。
