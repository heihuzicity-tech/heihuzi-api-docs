## 下载测试素材

- [reference.png](/images/reference.png)：1024×1024 蓝色杯子。
- [palette.png](/images/palette.png)：两图编辑测试使用的红色色板。
- [mask.png](/images/mask.png)：右侧有透明区域的 PNG 遮罩。

## 三个已经执行的编辑场景

| 场景 | 输入 | 编辑要求与实际结果 |
| --- | --- | --- |
| 单图改色 | reference.png | 蓝色杯子改为红色，保持杯形 |
| 两张参考图 | reference.png + palette.png | 使用第一张杯形和第二张红色，输出红色杯子 |
| 遮罩编辑 | reference.png + mask.png | 在右侧透明区域添加红苹果，输出保留蓝色杯子并新增右侧苹果 |

Flare、Sunburst 的三种场景均已使用 JSON 和 multipart 实测。GPT Image 2 已测试单图 JSON 和文件上传改色。下载参考图后，直接运行[图像编辑 API](/cn/api-reference/images/gpt-image-2/edits)中的完整代码。

JSON 使用 `images[].image_url`，multipart 单图使用 `image`、两图重复使用 `image[]`。JSON 遮罩使用 `mask.image_url`，文件遮罩使用 `mask`。请将返回图片另存，以便和参考图比较。
