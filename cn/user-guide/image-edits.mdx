---
title: "图像编辑"
description: "使用 gpt-image-2 编辑已有图片。"
---

图像编辑使用 `/v1/images/edits`，适合图生图、局部编辑、风格转换和参考图编辑。

## URL 输入

如果图片已经有公网可访问 URL，可以使用 JSON 请求体，把参考图放入 `images` 数组。

```json
{
  "model": "gpt-image-2",
  "prompt": "把这张照片变成水彩画风格",
  "images": [
    {
      "image_url": "https://assets.heihuzi.ai/photo.jpg"
    }
  ],
  "size": "1024x1024"
}
```

## 文件上传

如果图片在本地，使用 multipart 上传。该方式适合后台服务直接传文件，不需要先把图片放到公网。

## 遮罩

局部编辑可以传遮罩图。遮罩图需要和原图编辑区域语义一致，否则上游可能无法得到稳定结果。

## 排查

- 图片 URL 必须公网可访问。
- 本地文件上传需要使用 multipart。
- 权限错误先检查图片生成能力。
- 参数错误先对照 API 手册里的图像编辑接口。
