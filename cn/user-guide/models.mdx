本表记录 2026-09-10 的实际调用结果，GPT Image 2.6 两款为 2026-11-07。请先用自己的 Key 查询 [Models](/cn/models)。每个接口的额外参数、流式和图片格式范围，在对应 API 页面单独列出。

文本示例使用 `gpt-5.5`，Messages 示例使用 `claude-sonnet-5`。图片参数见[图片使用指南](/cn/user-guide/gpt-image-2)。

## Nano Banana 2.1

使用「Nano Banana 2.1 画图」分组 Key，模型 ID 为 `gemini-nano-banana-2.1`（旧 ID `gemini-3.1-flash-image` 仍可调用，自动转到 2.1），通过 Gemini 原生接口调用。见 [Nano Banana 2.1 使用指南](/cn/user-guide/nano-banana-2)。

## DeepSeek

使用 DeepSeek 分组 Key，并通过 `/v1/models` 确认 `deepseek-flash` / `deepseek-v4-pro` 可见。接口和实测范围见 [DeepSeek 接入](/cn/api-reference/deepseek/index)。

## GPT-6.2 与 Gemini 系列

- `gpt-6.2-astra`、`gpt-6.2-sol`：使用 ChatGPT 分组 Key，见 [GPT-6.2 接入](/cn/api-reference/gpt-6-2)。
- `gemini-3.8-flash`、`gemini-4-argon`、`gemini-4-carbon`、`gemini-4-hydrogen`：使用 Gemini 分组 Key，见 [Gemini 系列接入](/cn/api-reference/gemini)。

完整 ID 与对应分组权限必须同时匹配。上面的历史实测表保留原有日期；新型号的协议、参数和示例范围在专页单独说明。
