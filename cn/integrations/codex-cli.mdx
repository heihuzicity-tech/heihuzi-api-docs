将以下配置文件添加到 Codex CLI 配置目录中。文档中的 `<token>` 是占位符；真实内容以控制台「使用密钥」弹窗生成的配置为准。

<Tabs>
  <Tab title="Codex CLI">
    <Tabs>
      <Tab title="macOS / Linux">
        <Warning>
          请确保以下内容位于 `config.toml` 文件的开头部分。
        </Warning>
```toml ~/.codex/config.toml
model_provider = "OpenAI"
model = "gpt-5.5"
review_model = "gpt-5.5"
model_reasoning_effort = "xhigh"
disable_response_storage = true
network_access = "enabled"
windows_wsl_setup_acknowledged = true

[model_providers.OpenAI]
name = "OpenAI"
base_url = "https://code.heihuzi.ai"
wire_api = "responses"
requires_openai_auth = true

[features]
goals = true
```

```json ~/.codex/auth.json
{
  "OPENAI_API_KEY": "<token>"
}
```

        <Info>
          请确保配置目录存在。macOS/Linux 用户可运行 `mkdir -p ~/.codex` 创建目录。
        </Info>
      </Tab>

      <Tab title="Windows">
        <Warning>
          请确保以下内容位于 `config.toml` 文件的开头部分。
        </Warning>

## 使用建议

- 如果 Codex CLI 版本不支持 WebSocket，使用 `Codex CLI` 标签页里的标准配置。
- 如果模型不可用，先调用 `/v1/models` 确认当前 API Key 能看到目标模型。
- Codex CLI 的 `base_url` 使用 `https://code.heihuzi.ai`，不要手动追加 `/v1`。
- 不要把 Claude Code 的 `claude-*` 模型名配置到 Codex CLI 的 OpenAI provider。
