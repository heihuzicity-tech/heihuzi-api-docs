---
title: "黑胡子AI便利店 API"
description: "OpenAI-compatible、Claude Code-compatible 与 GPT Image 2 能力的统一 API 网关。"
---

黑胡子AI便利店对外提供三类 API 能力：OpenAI-compatible 调用、Claude Code-compatible 调用，以及 GPT Image 2 图像生成/编辑。文档里的接口契约以当前网关真实支持为准，不复制第三方平台的异步任务封装或私有字段。

## 选择入口

| 场景 | 推荐入口 | 说明 |
| --- | --- | --- |
| Codex / OpenAI 新项目 | `/v1/responses` | 主推荐文本、多模态和工具调用入口。 |
| 旧版 OpenAI 客户端迁移 | `/v1/chat/completions` | 兼容 `messages` 格式，不作为新项目首选。 |
| Claude Code | `/v1/messages` | Claude Code / Anthropic Messages-compatible 协议入口。 |
| 图像生成 | `/v1/images/generations` | GPT Image 2 文生图。 |
| 图像编辑 | `/v1/images/edits` | GPT Image 2 图生图、局部编辑和参考图编辑。 |
| 查询模型 | `/v1/models` | 返回当前 API Key 可见模型。 |

## 基础信息

<Info>
  Base URL：`https://code.heihuzi.ai`
</Info>

所有公开接口都使用 Bearer Token。Token 来自平台 API Key，实际可调用模型和能力由 API Key 所属分组、渠道配置和上游账号共同决定。

## 兼容边界

- OpenAI-compatible 不等于支持所有 OpenAI 字段，具体以每个接口页的参数说明为准。
- Claude Code-compatible 是网关兼容入口，不代表直接调用官方 Anthropic。
- GPT Image 2 采用当前网关的 OpenAI Images 兼容契约，不使用第三方平台的异步任务模式。
- 当前文档不公开任务查询、音频或文件上传接口。
