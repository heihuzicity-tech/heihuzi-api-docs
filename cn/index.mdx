API 地址：**`https://code.heihuzi.ai`**。文档验证日期：**2026-09-10**。

备用域名：如果你所在地区或当前网络无法访问 heihuzi.ai，可使用 [vim27.cc](https://vim27.cc) 访问便利店，使用 [docs.vim27.cc/cn](https://docs.vim27.cc/cn) 阅读 API 文档。API 备用入口为 `https://vim27.cc`；切换时只替换域名，保留原有接口路径。具体地址对照见[常见问题](/cn/faqs)。

本手册列出的请求、参数组合和代码示例已通过该地址实际调用。图片结果检查了编码、尺寸、数量及透明通道；流式检查了真实事件和最终图片。具体模型与组合范围列在对应接口页。

## 接口入口

| 能力 | 接口 |
| --- | --- |
| 查询模型 | `GET /v1/models` |
| Responses | `POST /v1/responses` |
| Chat Completions | `POST /v1/chat/completions` |
| Messages | `POST /v1/messages` |
| 图片生成 | `POST /v1/images/generations` |
| 图片编辑 | `POST /v1/images/edits` |
| Nano Banana 2 生成、编辑 | `POST /v1beta/models/gemini-3.1-flash-image:generateContent` |
| MiniMax 视频生成（官方格式） | `POST /v2/video_generation` |
| Seedance 视频生成 | `POST /api/v3/contents/generations/tasks` |

从[快速验证](/cn/quickstart)开始，或查看[集成指南](/cn/integrations/index)。所有请求都应使用与目标能力对应的 Key，认证和已复现错误见[认证](/cn/authentication)。

图片 API 按版本分组：GPT Image 2.5 提供生成、编辑和流式文档；GPT Image 2 提供独立的[生成](/cn/api-reference/images/gpt-image-2/generation)和[编辑](/cn/api-reference/images/gpt-image-2/edits)文档。模型选择统一见[图片使用指南](/cn/user-guide/gpt-image-2)。

## Nano Banana 2

已新增 [Nano Banana 2](/cn/api-reference/images/nano-banana-2/generation)（`gemini-3.1-flash-image`）的生成、编辑和流式文档。它使用 Gemini 原生接口，不走 `/v1/images/generations`；14 种比例、1K/2K/4K 清晰度和 1、2、14 张参考图均有实测记录，验证日期为 2026-10-03。用法总览见 [Nano Banana 2 使用指南](/cn/user-guide/nano-banana-2)。

## MiniMax 视频

已新增与 MiniMax 官方一致的[官方格式接口](/cn/api-reference/videos/minimax-v2/create)（`POST /v2/video_generation`）的创建、查询和删除文档，把官方地址和密钥换成便利店的即可；文档示例在生产 API 原样跑通，验证日期为 2026-10-06。原来的 [`/v1/videos` 写法](/cn/api-reference/videos/minimax/create)继续可用。

## Seedance 视频

已新增 [Seedance 视频](/cn/api-reference/videos/seedance/create)（Seedance 2.0、2.0 Fast、2.0 mini、2.5）的创建、查询和删除文档。请求和响应与火山方舟官方接口一致，按官方返回的实际用量计费；文生视频、首帧、首尾帧示例在生产 API 原样跑通，验证日期为 2026-10-05。

## DeepSeek

已新增 [DeepSeek 接入](/cn/api-reference/deepseek/index)，按模型列出通过验证的接口：Flash 的三种协议及流式、JSON、工具闭环、图片理解。验证日期为 2026-09-19，公开参数与完整示例均有对应的实测通过记录。
