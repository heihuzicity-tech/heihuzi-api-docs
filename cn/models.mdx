---

`/v1/models` 返回当前 API Key 可见的模型列表。文档中的推荐模型只表示平台支持方向，不承诺每个 Key 都能看到全部模型。

<RequestExample>
```bash cURL
curl --request GET \
  --url https://code.heihuzi.ai/v1/models \
  --header 'Authorization: Bearer <token>'
```

```python Python
import requests

response = requests.get(
    "https://code.heihuzi.ai/v1/models",
    headers={"Authorization": "Bearer <token>"},
)

print(response.json())
```
</RequestExample>

## 推荐模型族

| 类型 | 推荐模型 | 适用场景 |
| --- | --- | --- |
| GPT / Codex | `gpt-6-astra`、`gpt-5.6-sol`、`gpt-5.6-terra`、`gpt-5.6-luna`；兼容模型包括 `gpt-5.5`、`gpt-5.4`、`gpt-5.4-mini`、`gpt-5.3-codex-spark` | Responses、Chat Completions、Codex 工具链。 |
| Claude Code-compatible | `claude-opus-*`、`claude-sonnet-*`、`claude-haiku-*` | Claude Code / Messages 协议客户端。 |
| GPT Image | `gpt-image-2.5-flare`、`gpt-image-2.5-sunburst`、`gpt-image-2` | 图像生成和编辑；Images 省略 model 时默认 Flare。 |

2.5 的模型选择见[图像使用指南](/cn/user-guide/gpt-image-2)，质量档位与透明输出见[图像生成 API](/cn/api-reference/images/gpt-image-2/generation)。这里列出的是后端识别的常见模型名，不保证每把 Key 都有权限；不要使用 `gpt-image-2.5` 代替具体模型 ID。

## 注意事项

- 可见模型受 API Key、分组、渠道、上游账号状态影响。
- 普通调用不添加 `client_version` 查询参数；Codex 客户端携带该参数时，此路径可能返回 Codex 专用模型清单格式。
- 模型显示可见不等于每个参数都被该模型支持。
- Claude Code-compatible 模型是协议兼容入口，会按平台配置映射到可用上游。
