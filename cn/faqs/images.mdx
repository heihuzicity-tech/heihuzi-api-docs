## 为什么图片接口返回不支持？

Images 接口只面向 OpenAI-compatible 分组。非 OpenAI-compatible 分组访问图片接口时会返回不支持。

## 为什么提示没有图片权限？

API Key 所属分组需要开启图片生成能力。先确认 `/v1/models` 能看到 `gpt-image-2`，再检查分组能力。

## GPT Image 2 支持哪些尺寸？

优先使用明确像素尺寸，例如 `1024x1024`、`2048x1152`、`3840x2160`。如果使用 `auto`，最终尺寸由上游和服务端校验共同决定。

## 为什么不能照搬第三方平台的图像参数？

黑胡子AI便利店当前公开的是 OpenAI Images 兼容接口，不是第三方平台的异步任务封装。请以本 API 手册里的图像生成和图像编辑页面为准。

## 为什么没有异步任务查询？

当前公开 API 不提供图片任务轮询接口。图片接口按 OpenAI Images 兼容响应返回结果。
