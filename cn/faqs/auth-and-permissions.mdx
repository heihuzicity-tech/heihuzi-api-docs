## 为什么返回 401？

401 通常表示认证失败：

- 没有通过 `Authorization: Bearer` 或[兼容鉴权头](/cn/authentication)传入有效 Key。
- Bearer Token 格式错误。
- API Key 不存在、已失效或被停用。

先用同一个 Token 调用 `/v1/models`，确认认证是否正常。

## 为什么返回 403？

403 通常表示认证成功，但当前 Key 没有所需能力：

- 图片接口需要图片生成权限。
- Claude Code Messages 需要 Messages 调度权限。
- 目标模型或渠道不在当前分组里。

## 为什么返回 404？

404 可能表示路径写错，也可能表示目标模型或渠道对当前 Key 不可见。先检查接口路径，再查看 `/v1/models`。
