使用便利店的 DeepSeek 分组 API Key。**实测日期：2026-09-19**；以下结论来自便利店公网入口的真实请求，具体参数组合以各页示例为准。

## 地址与模型

| 客户端 | 配置地址 | 实际请求路径 |
| --- | --- | --- |
| OpenAI Python SDK | `https://code.heihuzi.ai/v1` | `/v1/chat/completions` 或 `/v1/responses` |
| Anthropic Python SDK | `https://code.heihuzi.ai` | `/v1/messages` |

环境变量 `HEIHUZI_API_KEY` 填写便利店 Key。OpenAI SDK 使用 Bearer 认证，Anthropic SDK 使用 `x-api-key`。不要把 DeepSeek 官方 Key 填到便利店地址。

本次 DeepSeek Key 查询 `/v1/models` 实际返回 `deepseek-flash` 和 `deepseek-v4-pro`。请先查[自己 Key 的模型列表](/cn/models)，其他分组的权限与可见模型可能不同。

| 模型 ID | 本次完成的验证 |
| --- | --- |
| `deepseek-flash` | 三种协议普通输出；三种协议流式；JSON；Chat / Responses 工具闭环；Responses 多轮；三种协议单图理解 |
| `deepseek-v4-pro` | Chat Completions、Responses、Messages 普通文本输出 |

DeepSeek 官方目前将 `deepseek-flash` 对应到 V4.1-Flash，并说明旧 Flash 名称的兼容关系；便利店本次模型列表仅返回上面的两个 ID，示例使用完整 ID。[官方模型说明](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)

## 安装与运行

本次执行环境使用 OpenAI Python SDK **2.32.0**、Anthropic Python SDK **0.97.0**。按所选页面安装对应 SDK，并在运行环境设置 `HEIHUZI_API_KEY`。所有示例关闭自动重试，单次超时为 120 秒，输出 token 参数为 1024。

示例中 `reasoning_effort` / `reasoning` / `thinking` 的取值只是已发送并核对的具体请求组合；**当前渠道不能据此保证思考已关闭或某个强度准确生效**。详见兼容性页。

## 计费与范围

费用以便利店当前分组配置和用量明细为准。官方的单价、优惠、上下文上限及并发配额不能直接作为便利店承诺。本次只做小请求功能验证，没有测试长上下文、最大输出或并发上限。缓存字段的返回情况见兼容性页。
