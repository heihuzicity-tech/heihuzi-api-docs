## 模型与接口

| 模型 | 通过的组合 |
| --- | --- |
| `deepseek-flash` | Chat Completions、Responses、Messages 普通文本与流式；Chat JSON；Chat / Responses 两轮工具；Responses 两轮历史；三种协议的单张 PNG 图片输入 |

## 已测参数与结果

| 协议与模型 | 参数组合 | 实际结果 |
| --- | --- | --- |
| Chat / Flash | `model`、`messages`、`max_tokens=1024` | 正确正文与正常完成标记 |
| Chat / Flash | `response_format.type="json_object"` | JSON 解析通过，字段与值符合断言 |
| Chat / Flash | `stream=true`、`stream_options.include_usage=true` | 完整正文、终止标记及用量 |
| Responses / Flash | `model`、`input`、`max_output_tokens=1024` | 正确正文、`status="completed"` |
| Responses / Flash | `stream=true` | 正文增量及 `response.completed` |
| Messages / Flash | `model`、`messages`、`max_tokens=1024` | 正确正文、`stop_reason="end_turn"` |
| Messages / Flash | SDK 开启 `stream=true` | 正文内容与 `message_stop` |
| Chat、Responses / Flash | `tools` 函数定义、指定 `add`、第二轮 `tool_choice="none"` | 参数 19、23，回传 42 后得到最终答案 |
| 三种协议 / Flash | 各协议的单图内容字段、base64 PNG | 识别出蓝色杯子 |

工具的嵌套参数和两轮完整请求见[工具调用](/cn/api-reference/deepseek/tools)；图片字段与编码见[图片理解](/cn/api-reference/deepseek/vision)。每种协议使用各自页面的请求格式。

## 完成与截断

Chat 的完整文本以 `finish_reason="stop"` 结束，Responses 为 `status="completed"`，Messages 为 `stop_reason="end_turn"`。流式也要检查最终完成标记，不能只凭收到文本片段判定完成。

Flash 的输出上限另以长输出请求验证：Chat 设置 `1024` 后返回 `length`，输出 token 为 1024；Messages 设置 `1024` 后返回 `max_tokens`，输出 token 为 1024；Responses 设置 `32` 后返回 `incomplete` 且原因为 `max_output_tokens`，输出 token 为 32。这些是截断结果，不能当作完整答案。

## 上下文与返回内容

Responses 多轮通过客户端回传完整历史完成。工具调用保留第一轮完整 assistant / output 对象，并使用返回的工具调用 ID 关联结果。

本轮响应可包含思考内容，客户端按相应协议提取最终正文。读取可选字段时检查是否存在；本页多轮示例中的容错读取已经与真实请求一起执行通过。

[DeepSeek 官方中文文档](https://api-docs.deepseek.com/zh-cn/)用于核对协议格式；便利店的使用说明以这里实际通过的组合为准。
