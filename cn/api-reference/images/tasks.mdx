---
title: "查询图片任务"
api: "GET /v1/images/tasks/{task_id}"
description: "查询异步图片任务的状态、结果和失败原因。"
---

使用[异步图像生成](/cn/api-reference/images/async-generation)或[异步图像编辑](/cn/api-reference/images/async-edits)返回的任务 ID。必须使用提交任务时的同一把 API Key。

<RequestExample>
```bash cURL
curl --include --request GET \
  --url "https://code.heihuzi.ai/v1/images/tasks/$TASK_ID" \
  --header "Authorization: Bearer $HEIHUZI_API_KEY"
```
</RequestExample>

<ParamField path="task_id" type="string" required>
  提交响应的 `id` 或 `task_id`，两者值相同，以 `imgtask_` 开头。
</ParamField>

## 状态

| status | 含义 | 下一步 |
| --- | --- | --- |
| `processing` | 正在处理 | 按 `Retry-After` 等待再查，通常为 3 秒 |
| `completed` | 图片生成及结果存储已完成 | 读取 `result.data[]` 并保存图片 |
| `failed` | 任务失败 | 读取 `error` 和 `http_status`，停止轮询 |

查询成功时 HTTP 为 200，即使任务本身已经失败；业务结果必须看 `status`。查询响应包含 `Cache-Control: no-store`。

## 完成响应

以下地址和 ID 为示例：

<ResponseExample>
```json
{
  "id": "imgtask_example",
  "task_id": "imgtask_example",
  "object": "image.generation.task",
  "status": "completed",
  "http_status": 200,
  "image_url": "https://example.com/generated.png",
  "result": {
    "created": 1788998400,
    "data": [{"url": "https://example.com/generated.png"}]
  },
  "created_at": 1788998400,
  "completed_at": 1788998460,
  "expires_at": 1789084860
}
```
</ResponseExample>

`image_url` 是第一张图片 URL 的便捷字段。多张输出必须遍历 `result.data[]`。`result` 保留 Images 兼容结果，图片经存储后通常以 URL 返回。`http_status` 是任务执行时的状态码，时间字段均为 Unix 秒。

失败时示例：

```json
{
  "id": "imgtask_example",
  "task_id": "imgtask_example",
  "object": "image.generation.task",
  "status": "failed",
  "http_status": 502,
  "error": {"type": "api_error", "message": "failed to store generated image to object storage"},
  "created_at": 1788998400,
  "completed_at": 1788998460,
  "expires_at": 1789084860
}
```

## 轮询示例

```python
import os
import time
import requests

task_id = os.environ["TASK_ID"]
headers = {"Authorization": f"Bearer {os.environ['HEIHUZI_API_KEY']}"}
deadline = time.monotonic() + 1800  # 客户端等待预算，自行按任务调整

while time.monotonic() < deadline:
    response = requests.get(
        f"https://code.heihuzi.ai/v1/images/tasks/{task_id}",
        headers=headers,
        timeout=30,
    )
    response.raise_for_status()
    task = response.json()
    if task["status"] == "completed":
        print(task["result"])
        break
    if task["status"] == "failed":
        raise RuntimeError(task.get("error"))
    time.sleep(max(1, int(response.headers.get("Retry-After", "3"))))
else:
    raise TimeoutError("停止本地轮询；保留 task_id，稍后继续查询，不要重复提交")
```

## 404 与过期

任务不存在、过期，或不属于当前用户及 API Key 时均返回 404，错误类型为 `IMAGE_TASK_NOT_FOUND`。不能通过这个错误判断别人的任务是否存在。任务存储不可用时可能返回 503。

默认任务保留时间为 24 小时，完成时会刷新保留时间；以每次查询的 `expires_at` 为准。管理员关闭新任务提交后，已有且未过期的任务仍可继续查询，只要任务存储可用。
