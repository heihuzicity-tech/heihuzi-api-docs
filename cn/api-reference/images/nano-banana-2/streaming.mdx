Nano Banana 2 支持 Gemini 原生流式接口：`POST https://code.heihuzi.ai/v1beta/models/gemini-3.1-flash-image:streamGenerateContent?alt=sse`，请求体与[图像生成](/cn/api-reference/images/nano-banana-2/generation)相同。验证日期：**2026-10-03**。

## 真实观测

| 请求 | 鉴权头 | 事件数 | 收到图片 | 结果 |
| --- | --- | --- | --- | --- |
| `1:1`、`1K` | `x-goog-api-key` | 1 | 11.04 秒 | 1024×1024 JPEG，`finishReason: STOP` |
| `16:9`、`2K` | `Authorization: Bearer` | 1 | 22.5 秒 | 2752×1536 JPEG，`finishReason: STOP` |

两次都只收到**一个事件**，里面同时包含完整图片、`finishReason` 和 `usageMetadata`；没有预览图或分段图片。流式的作用是在等待期间保持连接，不会更早拿到图片。上表是实测耗时记录，不是响应时间承诺。

## cURL 保存原始事件流

```bash
curl --fail-with-body --silent --show-error --max-time 600 --no-buffer \
  --request POST \
  --url 'https://code.heihuzi.ai/v1beta/models/gemini-3.1-flash-image:streamGenerateContent?alt=sse' \
  --header "x-goog-api-key: $HEIHUZI_API_KEY" \
  --header 'Content-Type: application/json' \
  --data '{
  "contents": [
    {
      "role": "user",
      "parts": [{"text": "A simple blue ceramic cup on a white background."}]
    }
  ],
  "generationConfig": {
    "responseModalities": ["IMAGE"],
    "imageConfig": {"aspectRatio": "1:1", "imageSize": "1K"}
  }
}' \
  --output stream.sse
```

完整事件流保存到 `stream.sse`。每个事件是一行 `data: {...}`，`{...}` 的结构与非流式响应相同，不能把整个文件当作一个 JSON 读取。下面的命令取出其中的图片，保存为 `stream.jpg`：

```bash
python3 - <<'EOF'
import base64
import json

saved = 0
for line in open("stream.sse"):
    if not line.startswith("data:"):
        continue
    event = json.loads(line[5:])
    for candidate in event.get("candidates", []):
        for part in candidate.get("content", {}).get("parts", []):
            if "inlineData" in part and not part.get("thought"):
                saved += 1
                open("stream.jpg", "wb").write(base64.b64decode(part["inlineData"]["data"]))
print("Saved", saved, "image(s)")
EOF
```

## Python SDK 流式保存图片

需要 `google-genai` 1.49.0 及以上：更早的版本没有 `image_size` 字段，运行会报错。这段代码已用 `google-genai==2.28.0`（需要 Python 3.10 及以上）真实执行，收到一个事件并保存 1024×1024 JPEG 到 `stream-1.jpg`。

```python
import os

from google import genai
from google.genai import types

client = genai.Client(
    api_key=os.environ["HEIHUZI_API_KEY"],
    http_options=types.HttpOptions(base_url="https://code.heihuzi.ai", timeout=600_000),
)
saved = 0
for chunk in client.models.generate_content_stream(
    model="gemini-3.1-flash-image",
    contents="A simple blue ceramic cup on a white background.",
    config=types.GenerateContentConfig(
        response_modalities=["IMAGE"],
        image_config=types.ImageConfig(aspect_ratio="1:1", image_size="1K"),
    ),
):
    for candidate in chunk.candidates or []:
        for part in candidate.content.parts or []:
            if part.inline_data and not part.thought:
                saved += 1
                with open(f"stream-{saved}.jpg", "wb") as file:
                    file.write(part.inline_data.data)
if saved == 0:
    raise RuntimeError("No image returned")
print("Saved", saved, "image(s)")
```

以收到可解码的图片为成功依据，不要假设一定会先收到预览。
