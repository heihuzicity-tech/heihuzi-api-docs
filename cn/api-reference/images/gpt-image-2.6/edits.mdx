本页适用于 GPT Image 2.6。使用 2.5 请查看 [GPT Image 2.5 API](/cn/api-reference/images/gpt-image-2.5/edits)。

通过 `POST https://code.heihuzi.ai/v1/images/edits` 上传参考图并描述修改要求。验证日期：**2026-11-07**。请使用具有 GPT Image 2.6 权限的 API Key，并设置环境变量 `HEIHUZI_API_KEY`。

## 输入方式

| 输入方式 | 本次验证的字段 | 模型 |
| --- | --- | --- |
| 文件上传 | multipart 文件字段 `image`；多张时重复上传 `image[]` | Flare、Sunburst |
| JSON Data URL | `images: [{"image_url": "data:image/png;base64,..."}]` | Flare、Sunburst |
| JSON 图片地址 | `images: [{"image_url": "https://..."}]` | Sunburst |

下载[参考图 reference.png](/images/reference.png)到运行目录后，可以直接运行下面的示例。

<RequestExample>
```bash
curl --fail-with-body --silent --show-error --max-time 600 \
  --request POST \
  --url https://code.heihuzi.ai/v1/images/edits \
  --header "Authorization: Bearer $HEIHUZI_API_KEY" \
  --form 'model=gpt-image-2.6-sunburst' \
  --form 'prompt=Change the blue cup to a bright red cup. Keep the cup shape and the white background.' \
  --form 'image=@reference.png' \
  --form 'n=1' \
  --form 'size=1024x1024' \
  --form 'quality=low' \
  --form 'output_format=png' \
  --output edits-multipart.json
```
</RequestExample>

响应保存为 `edits-multipart.json`，其中 `data[].b64_json` 是输出图片。

## 请求参数

参数名、取值和返回结构与 OpenAI 官方 `POST /v1/images/edits` 一致。下面只列编辑接口实际调用过的取值，具体组合见[已验证的参数组合](#已验证的参数组合)。

<ParamField body="model" type="string" required>
填写 `gpt-image-2.6-flare` 或 `gpt-image-2.6-sunburst`。省略时本站使用 `gpt-image-2.5-flare`，和官方默认的 `gpt-image-2.5-sunburst` 不同，要用 2.6 请明确填写。
</ParamField>

<ParamField body="prompt" type="string" required>
描述要怎样修改参考图。
</ParamField>

<ParamField body="images" type="object[]">
JSON 参考图数组，已验证一张和两张参考图。multipart 改用 `image` 文件字段，多张时重复上传 `image[]`。
<Expandable title="JSON 参考图字段" defaultOpen>
<ParamField body="image_url" type="string">参考图的完整 Data URL 或公开的 `https` 图片地址，本次验证 PNG。</ParamField>
</Expandable>
官方的 `images[].file_id` 本站不支持，实测返回 400，请改用 `image_url`。
</ParamField>

<ParamField body="background" type="string">
已验证 `transparent`：配 `png` 得到透明背景的 PNG。实际背景以响应里的 `background` 为准。
</ParamField>

<ParamField body="complexity" type="string">
出图前构思的程度，已验证 `low`、`medium`、`high`，输出用量不变。
</ParamField>

<ParamField body="frame_count" type="integer">
GIF 的帧数，只用于 `output_format: "gif"`。已验证 `2`、`4`、`9`、`12`、`16`，不填时为 9 帧。
</ParamField>

<ParamField body="frame_duration_ms" type="integer">
GIF 每帧时长，单位毫秒。已验证 `20`、`100`、`200`、`500`、`2000`，不填时为 200。
</ParamField>

<ParamField body="moderation" type="string">
内容审核档位，已验证 `low`、`auto`。
</ParamField>

<ParamField body="n" type="integer" default="1">
返回图片张数，已验证 `1`、`2`、`10`。一次出多张时，参考图的输入用量按张数重复计算：一张 1024×1024 参考图出 10 张，计 10240 个图片输入用量。
</ParamField>

<ParamField body="output_compression" type="integer">
已验证 `jpeg` 填 `50`。
</ParamField>

<ParamField body="output_format" type="string">
已验证 `png`、`jpeg`、`webp`、`gif`。GIF 两款型号、multipart 和 JSON 两种写法都验证过，见下方[参考图生成 GIF](#参考图生成-gif)。
</ParamField>

<ParamField body="partial_images" type="integer">
流式返回时的预览张数。已验证 `1`、`2`：填 `2` 收到 2 张预览，填 `1` 没有收到预览。请求 `webp` 时预览图仍是 PNG，完成图是 WebP。
</ParamField>

<ParamField body="quality" type="string">
已验证 `low`、`medium`、`high`、`xhigh`、`max`、`auto`。`auto` 本次实际落在 `medium`，以响应里的 `quality` 为准。
</ParamField>

<ParamField body="safety_identifier" type="string">
用于标识你这边的终端用户，响应里会原样返回。同时填写已弃用的 `user` 时，响应以 `safety_identifier` 为准。
</ParamField>

<ParamField body="size" type="string">
已验证 `1024x1024`、`1536x1024`、`1024x1536`、`2048x2048`、`2880x2880`、`auto`（本次返回 `1374x1145`）。GIF 不填和填 `512x512` 都输出 512×512，填 `1024x1024` 返回 400。
</ParamField>

<ParamField body="stream" type="boolean" default="false">
设置 `true` 后返回 SSE。Flare、Sunburst，multipart 和 JSON 请求都验证过。完成事件是 `image_edit.completed`；填了 `partial_images` 时，之前可能先收到 `image_edit.partial_image` 预览事件。请以完成事件作为成功依据。
</ParamField>

## JSON 编辑并保存图片

这段完整代码已真实执行，把蓝色杯子改成红色并保存为 `edited-1.png`。

```python
import base64
import os
from pathlib import Path
import requests

encoded = base64.b64encode(Path("reference.png").read_bytes()).decode("ascii")
response = requests.post(
    "https://code.heihuzi.ai/v1/images/edits",
    headers={"Authorization": f"Bearer {os.environ['HEIHUZI_API_KEY']}"},
    json={
        "model": "gpt-image-2.6-flare",
        "prompt": "Change the blue cup to a bright red cup. Keep the cup shape and the white background.",
        "images": [{"image_url": f"data:image/png;base64,{encoded}"}],
        "n": 1,
        "size": "1024x1024",
        "quality": "low",
        "output_format": "png",
    },
    timeout=600,
)
response.raise_for_status()
data = response.json()["data"]
for index, item in enumerate(data, 1):
    Path(f"edited-{index}.png").write_bytes(base64.b64decode(item["b64_json"]))
print("Saved", len(data), "image(s)")
```

## 参考图生成 GIF

这段完整代码已真实执行，让参考图里的杯子上下跳动，保存为 512×512、9 帧的 `cup-bounce.gif`。

```python
import base64
import os
from pathlib import Path
import requests

encoded = base64.b64encode(Path("reference.png").read_bytes()).decode("ascii")
response = requests.post(
    "https://code.heihuzi.ai/v1/images/edits",
    headers={"Authorization": f"Bearer {os.environ['HEIHUZI_API_KEY']}"},
    json={
        "model": "gpt-image-2.6-flare",
        "prompt": "Make the blue cup gently bounce up and down.",
        "images": [{"image_url": f"data:image/png;base64,{encoded}"}],
        "quality": "low",
        "output_format": "gif",
        "frame_count": 9,
        "frame_duration_ms": 200,
    },
    timeout=600,
)
response.raise_for_status()
item = response.json()["data"][0]
Path("cup-bounce.gif").write_bytes(base64.b64decode(item["b64_json"]))
print("Saved cup-bounce.gif")
```
