---
title: "提交异步图像生成"
api: "POST /v1/images/generations/async"
description: "复用图像生成参数，先返回任务 ID，再查询图片结果。"
---

适合不希望长时间保持生成连接的客户端。请求参数与[图像生成](/cn/api-reference/images/gpt-image-2/generation)一致，必须省略 `stream` 或设置为 `false`。

<Info>
  该接口是本平台的扩展接口，需要服务端启用图片异步任务和结果存储。未启用时返回 404，消息为 `async image tasks are not enabled`。它不属于 OpenAI SDK 标准的 Images 方法。
</Info>

<RequestExample>
```bash cURL
curl --include --request POST \
  --url https://code.heihuzi.ai/v1/images/generations/async \
  --header "Authorization: Bearer $HEIHUZI_API_KEY" \
  --header 'Content-Type: application/json' \
  --data '{
    "model": "gpt-image-2.5-flare",
    "prompt": "一张极简风格的蓝色 API 网关图标",
    "n": 1,
    "size": "1024x1024",
    "quality": "low",
    "output_format": "png"
  }'
```
</RequestExample>

## 接收响应

成功接收返回 **HTTP 202**，并包含 `Location` 查询路径、`Retry-After: 3` 和 `Cache-Control: no-store`。以下 ID 为示例：

<ResponseExample>
```json
{
  "id": "imgtask_example",
  "task_id": "imgtask_example",
  "object": "image.generation.task",
  "status": "processing",
  "created_at": 1788998400,
  "expires_at": 1789084800,
  "poll_url": "/v1/images/tasks/imgtask_example"
}
```
</ResponseExample>

202 仅表示任务已接收。保存 `task_id`，使用提交时的同一把 API Key 调用[查询图片任务](/cn/api-reference/images/tasks)，直到 `completed` 或 `failed`。`poll_url` 为相对路径，拼接到 `https://code.heihuzi.ai` 后访问。

## 限制

- GPT Image 异步提交需要 OpenAI 类型分组及图片生成权限；同步接口可用不代表异步功能一定已启用，合成分组也不能据此假设可用。
- `stream: true` 返回 400：`streaming image requests cannot be submitted as asynchronous tasks`。
- 任务按用户和 API Key 绑定，不能换另一把 Key 查询。
- 每次有效提交会创建新任务；本接口没有可依赖的幂等键契约。网络超时后避免盲目重发。
- 任务有过期时间，以返回的 `expires_at` 为准。完成后及时保存结果，不要把任务存储当作永久图库。
