---
title: "Seedance 视频：删除任务"
description: "删除已结束的 Seedance 任务记录；生成中的任务不能删除。"
api: "DELETE /api/v3/contents/generations/tasks/{id}"
---

删除已结束任务的记录。请求和响应的格式与火山方舟「取消或删除视频生成任务」接口相同。

<RequestExample>
```bash
curl --fail-with-body --silent --show-error \
  --request DELETE \
  --url "https://code.heihuzi.ai/api/v3/contents/generations/tasks/$TASK_ID" \
  --header "Authorization: Bearer $HEIHUZI_API_KEY"
```
</RequestExample>

## 路径参数

<ParamField path="id" type="string" required>
创建任务返回的 `id`。只能操作自己创建的任务。
</ParamField>

## 不同状态的结果

| 任务状态 | 结果 |
| --- | --- |
| `running`（生成中） | **不能删除**，返回 409 `InvalidAction.RunningTaskDeletion`，任务继续生成并照常扣费 |
| `succeeded`（已完成） | 先完成结算，再删除记录，返回 200；删除后再查询返回 404 |

任务提交后通常很快开始生成，开始后无法撤回，请确认参数后再提交。

## 响应

删除已完成的任务：

<ResponseExample>
```json
{}
```
</ResponseExample>

删除生成中的任务：

```json
{"error":{"code":"InvalidAction.RunningTaskDeletion","message":"Cannot delete task `cgt-20261005162359-6cgkk` because it is currently running. Request id: …","param":"","type":"Conflict"}}
```

删除后已完成任务的成片链接不再能通过查询接口获取，删除前请先下载保存。
