用[创建任务](/cn/api-reference/videos/minimax-v2/create)返回的 `task_id` 查询，返回结构与[官方查询接口](https://platform.minimaxi.com/docs/api-reference/video-generation-v2-query)一致。验证日期：**2026-10-06**。

<RequestExample>
```bash
curl --fail-with-body --silent --show-error \
  --url "https://code.heihuzi.ai/v2/query/video_generation/$TASK_ID" \
  --header "Authorization: Bearer $HEIHUZI_API_KEY"
```
</RequestExample>

运行前把环境变量 `TASK_ID` 设为创建任务返回的 `task_id`。

## 路径参数

<ParamField path="task_id" type="string" required>
创建任务返回的 `task_id`。只能查询自己的任务，查不到时返回 404。
</ParamField>

## 状态

`task.status` 依次为 `queued`（排队中）→ `running`（生成中）→ `succeeded`（成功）。成功后 `task.content.url` 是成片链接，`task.usage.output_seconds` 是实际计费秒数。

`MiniMax-H3-Max` 实测 10–20 秒出片（文生示例：第 0、5 秒为 `queued`，第 10 秒为 `succeeded`；首帧示例：第 10、15 秒为 `running`，第 20 秒为 `succeeded`），建议每 5 秒左右查询一次。

## 真实响应

成功时（`content.url` 为签名链接，此处省略）：

<ResponseExample>
```json
{"task":{"content":{"url":"https://…"},"created_at":1791284616,"duration":5,"id":"video_e992bbae16f64f0fa2ef2d18d5a22360","modality":"video","model":"MiniMax-H3-Max","ratio":"16:9","resolution":"480P","status":"succeeded","task_type":"generation","updated_at":1791284627,"usage":{"input_image_count":0,"input_seconds":0,"output_seconds":5,"total_seconds":5}}}
```
</ResponseExample>

带首帧图时 `ratio` 为 `adaptive`，`usage.input_image_count` 为 `1`。成片链接有有效期，请及时下载保存。
