`POST https://code.heihuzi.ai/v1/messages` 已验证 `claude-sonnet-5`、`claude-opus-5`、`claude-haiku-4-5-20251001`。请使用对应的 Messages API Key。

<RequestExample>
```bash
curl --fail-with-body --silent --show-error --max-time 600 \
  --request POST \
  --url https://code.heihuzi.ai/v1/messages \
  --header "Authorization: Bearer $HEIHUZI_API_KEY" \
  --header 'Content-Type: application/json' \
  --data '{
  "model": "claude-sonnet-5",
  "max_tokens": 256,
  "messages": [
    {
      "role": "user",
      "content": "Reply with exactly API_OK."
    }
  ]
}' \
  --output messages.json
```
</RequestExample>

## 请求参数

<ParamField body="model" type="string" required>填写完整模型 ID；省略模型实测返回 400。</ParamField>
<ParamField body="max_tokens" type="integer">本页三种模型的文本用例均填写 `256`。</ParamField>
<ParamField body="messages" type="object[]">示例使用一条 `role: "user"`、`content` 为字符串的消息。</ParamField>
<ParamField body="stream" type="boolean">Sonnet 5 已验证省略返回 JSON，设为 `true` 返回 SSE。</ParamField>

## 真实响应节选

```json
{
  "type": "message",
  "role": "assistant",
  "model": "claude-sonnet-5",
  "content": [
    {
      "text": "API_OK",
      "type": "text"
    }
  ],
  "stop_reason": "end_turn",
  "usage": {
    "cache_creation_input_tokens": 50,
    "cache_read_input_tokens": 13,
    "input_tokens": 12,
    "output_tokens": 3
  }
}
```

从 `content[]` 的 `type: "text"` 对象读取 `text`。Sonnet 5 的流式用例仅在上述示例请求体中增加 `stream: true`；实测收到 `message_start`、`content_block_delta`、`message_delta`、`message_stop`，文字位于 `content_block_delta` 事件的 `delta.text`。

Claude Code 的客户端接入见 [Claude Code](/cn/integrations/claude-code)。模型记录见[模型与调用结果](/cn/api-reference/claude-code)。
