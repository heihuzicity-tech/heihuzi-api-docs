`POST https://code.heihuzi.ai/v1/responses` 已验证文本生成。五个文本模型见 [Models](/cn/models)；本页扩展输入及流式测试使用 `gpt-5.5`。

<RequestExample>
```bash
curl --fail-with-body --silent --show-error --max-time 600 \
  --request POST \
  --url https://code.heihuzi.ai/v1/responses \
  --header "Authorization: Bearer $HEIHUZI_API_KEY" \
  --header 'Content-Type: application/json' \
  --data '{
  "model": "gpt-5.5",
  "input": "Reply with exactly API_OK."
}' \
  --output responses.json
```
</RequestExample>

## 已验证的输入

| 请求形式 | 实际验证 |
| --- | --- |
| `input` 字符串 | 五个文本模型均返回文本 |
| `input` 消息数组 | `[{"role":"user","content":"Reply with exactly API_OK."}]` 搭配 `stream: true` 返回 SSE 文本 |
| 图片输入 | `gpt-5.5` 的 `input_text` + `input_image` Data URL 正确识别蓝色杯子 |
| 自定义函数 | `gpt-5.5` 调用 `add`，客户端回传函数结果后模型回答 `5` |

## 真实响应节选

```json
{
  "object": "response",
  "status": "completed",
  "output": [
    {
      "id": "msg_0e0caf29cbdbf6a6016aa2370876a087d08ec5232de4e272aa",
      "type": "message",
      "status": "completed",
      "content": [
        {
          "type": "output_text",
          "annotations": [],
          "logprobs": [],
          "text": "API_OK"
        }
      ],
      "phase": "final_answer",
      "role": "assistant"
    }
  ]
}
```

非流式文本读取 `output[]` 中 `type: "message"` 的 `content[]`，其中 `type: "output_text"` 的 `text` 为文字。OpenAI SDK 也可使用 `output_text`，见[SDK 示例](/cn/integrations/openai-sdk)。

`stream: true` 的实测事件包括 `response.output_text.delta` 和 `response.completed`。缺少 `model` 或 `input` 的请求已验证返回 400。

## 自定义函数完整示例

下面代码已真实执行两次 API 调用：先获取 `add` 调用，再提交本地计算结果。

```python
import json
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["HEIHUZI_API_KEY"],
    base_url="https://code.heihuzi.ai/v1",
    timeout=600.0,
    max_retries=0,
)
inputs = [{"role": "user", "content": "Use add to calculate 2 plus 3, then answer with the number only."}]
response = client.responses.create(
    model="gpt-5.5",
    input=inputs,
    tools=[{
        "type": "function",
        "name": "add",
        "description": "Add two numbers.",
        "parameters": {
            "type": "object",
            "properties": {"a": {"type": "number"}, "b": {"type": "number"}},
            "required": ["a", "b"],
            "additionalProperties": False,
        },
        "strict": True,
    }],
    tool_choice={"type": "function", "name": "add"},
)
calls = [item for item in response.output if item.type == "function_call"]
if len(calls) != 1 or calls[0].name != "add":
    raise RuntimeError("Expected one add call")
call = calls[0]
args = json.loads(call.arguments)
value = args["a"] + args["b"]
inputs.extend(item.model_dump() for item in response.output)
inputs.append({"type": "function_call_output", "call_id": call.call_id, "output": str(value)})
final = client.responses.create(model="gpt-5.5", input=inputs)
print(final.output_text)
```

图像生成与编辑使用 [Images 接口](/cn/api-reference/images/gpt-image-2/generation)。本页的图片输入测试用于识别参考图内容。
